# Professional Portfolio Website for Augusto Corvalan

## Content 
Content to support:
- Portfolio
- Blog

### Portfolio
- Goes under "About" section of the website
- Showcases different vericals of work (e.g. editorial, publication, engineering, design)
- Each vertical has a landing page with a grid of projects, and each project has its own page with more details and images.
- Each project page includes a description of the project, the role Augusto played, the tools and technologies used, and any relevant links (e.g. GitHub, live demo, etc.)
- Will have different versions of portfolio pages for different audiences - for example a more technical version would include only engineering, a more design-focused would include editorial+publication+design, one will include all verticals, etc. For the this project, the regular /about page will include only engineering verticals, while /about-all will include all verticals (editorial, publications, engineering, design). The /about-all will not be linked anywhere on the website, but will be shared with specific audiences as needed.
- Each vertical should be easy to reuse in different portfolio pages and easy to extend.

### Blog
- Nothing on this yet, but will include posts about design, engineering, and other topics related to Augusto's work and interests. Will be added in a later phase of the project.

## Design
- Minimalist, clean, modern design.
- Use of whitespace to create a sense of openness and clarity.
- Consistent typography and color scheme throughout the website.
- Responsive design that works well on both desktop and mobile devices.
- Color scheme is black and white with accents of yellow. Thick borders, lines and bold typography to create a strong visual impact. Use of geometric shapes and patterns to add visual interest and break up the content. Overall, the design should be bold, modern, brutalist and visually striking while still maintaining a sense of simplicity and elegance.

### Homepage
- Clean minimalist nav up top with links to "About" and "Contact"
- Large hero section with Augusto Corvalan's name, a brief tagline, and a call-to-action button that leads to the portfolio section of the website.
- Logo is the letters AC

### Portfolio Landing Page
- For each vertical, there will be a section with a title. Clicking on the title will expand the section to show a grid of projects related to that vertical. Each project will have a thumbnail image, title, and brief description. Clicking on a project will take the user to the project page with more details and images.

### Portfolio Item Page
- Will have space for several hero images at the top (pinterest style layout), followed by a description of the project, the role Augusto played, the tools and technologies used, and any relevant links (e.g. GitHub, live demo, etc.)
